# 1. Information We Collect

Aria collects only the information required to provide music features.
## Discord Information
Last Updated: July 26, 2026

Aria may collect:

- Discord User ID

Aria may process:

- Music search queries
- Song names and URLs requested by users
- Queue information
- Currently playing track information
- Server music settings (such as volume preferences or configuration)

## Technical Information

Aria may collect limited technical information such as:

- Command usage logs
- Error logs
- Bot performance data

This information is used only to maintain, improve, and provide Aria's features.
